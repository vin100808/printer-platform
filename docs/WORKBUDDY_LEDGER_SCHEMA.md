# WorkBuddy 运营台账设计（企业微信智能表方案）

> 本文档把《PRINTING_OPERATIONS_RULES.md》的业务规则映射为「企业微信智能表 + WorkBuddy」的轻量运营台账。
> 目标不是复制 Web 平台的数据库结构，而是设计一组业务人员能直接看懂、WorkBuddy 能可靠读写的台账表。
> 凡本文档与业务规则文件不一致处，以业务规则文件为准。

**不要**把 Web 平台的历史技术模型（Location、FrameworkContract、SupplierOrder、SupplierOrderItem 等）复制进智能表。新业务只需要以下 8 张表。

---

## 总体结构

```
客户 ──┐                    ┌── 供应商
       ├── 订单 ── 订单明细 ──┤
套餐 ──┘        │            └── 套餐
机型库 ─────────┴── 设备 ── 抄表记录
```

- 订单明细是「订单 × 套餐 × 数量」；
- 设备挂在订单明细下，是抄表和结算的最小单位；
- 抄表记录挂在设备下，一台设备一个月一条。

---

## 表 1｜客户

**业务用途**：记录所有租赁客户的主体资料。

| 字段 | 必要性 | 说明 |
|---|---|---|
| 客户编码 | 必填，自动生成 | C0001 起递增，创建后不改、不复用 |
| 客户名称 | 必填 | 查重主键 |
| 客户类型 | 必填 | 内部 / 外部 |
| 状态 | 必填 | 正常 / 停用 |
| 税号 | 可选 | |
| 注册地址 | 可选 | 公司工商地址，与设备安装地址无关 |
| 银行名称 / 户名 / 账号 | 可选 | 开票回款用 |
| 联系人 / 联系电话 | 可选 | |
| 备注 | 可选 | |

- **关联**：被「订单」引用；被「套餐」（客户专属套餐）引用。
- **自动计算**：该客户订单数、在用设备数（智能表关联统计，可选）。
- **不应重复保存**：订单、设备上的任何冗余客户资料（除名称快照外不需要）。
- **查重规则**：按客户名称查重；同名不同主体的，由人工确认后再建。
- **新增 / 更新规则**：基础资料允许更新；有订单或套餐引用的客户不删除，只停用。

## 表 2｜供应商

**业务用途**：记录设备与服务的上游供应商。

| 字段 | 必要性 | 说明 |
|---|---|---|
| 供应商编码 | 必填，自动生成 | S0001 起递增 |
| 供应商名称 | 必填 | 查重主键 |
| 状态 | 必填 | 正常 / 停用 |
| 税号 / 注册地址 / 银行资料 | 可选 | |
| 联系人 / 联系电话 | 可选 | |
| 服务区域 | 可选 | |
| 备注 | 可选 | |

- **关联**：被「订单」「套餐（供应商套餐）」引用。
- **查重 / 新增 / 更新规则**：同客户表。

## 表 3｜套餐

**业务用途**：统一存放客户套餐与供应商套餐的价格条款及版本历史。

| 字段 | 必要性 | 说明 |
|---|---|---|
| 套餐编码 | 必填 | 同一编码代表同一款套餐的议价脉络 |
| 版本 | 必填 | 整数，从 1 开始；（套餐编码 + 版本）唯一 |
| 套餐名称 | 必填 | |
| 套餐侧别 | 必填 | 客户套餐 / 供应商套餐 |
| 归属客户 | 客户专属套餐必填 | 为空 = 标准套餐（所有客户可用）；仅客户套餐使用 |
| 归属供应商 | 供应商套餐必填 | 仅供应商套餐使用 |
| 月租（元/月） | 必填 | |
| 免费额度（BW Equivalent/月） | 必填 | |
| 超印单价（元/BW Equivalent） | 必填 | |
| 生效日期 | 必填 | |
| 适配机型 | 可选 | 关联机型库，可多选 |
| 状态 | 必填 | 正常 / 停用 |
| 备注 | 可选 | |

- **关联**：被「订单明细」（客户套餐）引用；供应商套餐被「供应商」归属。
- **不应重复保存**：不在订单 / 设备上另存价格快照——结算始终读取明细引用的套餐版本。
- **查重规则**：（套餐编码 + 版本）唯一。
- **新增 / 更新规则**：**价格字段创建后不可修改**；重新议价 = 同编码新建版本（复制旧版本改价格），旧版本保留可停用。被任何订单明细引用的版本不删除。

## 表 4｜机型库

**业务用途**：打印机标准产品目录。

| 字段 | 必要性 | 说明 |
|---|---|---|
| 品牌 | 必填 | （品牌 + 型号）唯一 |
| 型号 | 必填 | |
| 设备类型 | 必填 | 黑白 / 彩色；决定抄表是否要彩色读数 |
| 状态 | 必填 | 正常 / 停用 |
| 备注 | 可选 | |

- **关联**：被「设备」引用；被「套餐」多选关联。
- **查重规则**：品牌 + 型号组合查重。
- **新增 / 更新规则**：被设备引用的机型不删除。

## 表 5｜订单

**业务用途**：一张订单 = 一次完整租赁交易（客户 + 地址 + 供应商 + 套餐明细 + 租期 + 押金）。

| 字段 | 必要性 | 说明 |
|---|---|---|
| 订单号 | 必填，自动生成 | YYYYMMDD + 当日两位序号（如 2026092301），全局唯一、不复用 |
| 客户 | 必填 | 关联客户表；**创建后不可改** |
| 供应商 | 必填（新单） | 关联供应商表；历史单允许未知留空 |
| 安装地址 | 必填 | 手填文本 |
| 开始日期 | 必填 | |
| 结束日期 | 可选 | 默认 = 开始日期 + 3 年 − 1 天，可改，不得早于开始日期 |
| 结算方式 | 必填 | 按月结算 / 按自然季度结算 |
| 押金应收 | 自动计算 | = 全部明细数量合计 × 2,000 元 |
| 押金收款日期 | 可选 | 空 = 未收；有值 = 已收 |
| 下单日期 | 必填 | 默认当天 |
| 状态 | 必填 | 草稿 / 履约中 / 已结束 / 已取消 |
| 合同文件 | 可选 | 附件 |
| 订单附件 | 可选 | 附件（与合同文件独立） |
| 备注 | 可选 | |

- **关联**：客户、供应商；下挂「订单明细」。
- **自动计算**：押金应收、明细合计数量、已部署合计、部署状态（未部署 / 部分部署 / 已部署）。
- **不应重复保存**：部署进度不存数值字段（由设备台账统计）；结算金额不存（由抄表 + 套餐现算）。
- **查重规则**：订单号唯一；业务上「同客户 + 同地址 + 同开始日期」高度疑似重复，建单前必须查重确认。
- **新增 / 更新规则**：
  - 新增设备必须新建订单，禁止改历史明细数量表示新增。
  - 可改：供应商、地址、起止日期、结算方式、下单日期、状态、备注、文件。不可改：客户。
  - 结束订单只改状态为「已结束」，不动任何设备与抄表。
  - 已取消订单不可再进场设备。
  - 有设备的订单不删除。

## 表 6｜订单明细

**业务用途**：订单内「套餐 × 数量」的逐行约定；是设备进场的挂载点。

| 字段 | 必要性 | 说明 |
|---|---|---|
| 所属订单 | 必填 | 关联订单表 |
| 套餐 | 必填 | 关联套餐表（客户套餐，且对该订单客户可用） |
| 数量 | 必填 | 整数 ≥ 1 |
| 已部署台数 | 自动计算 | 本明细下「运行中」设备数 |
| 部署状态 | 自动计算 | 未部署 / 部分部署 / 已部署 |
| 计划进场日期 | 可选 | 仅作计划参考（历史习惯字段，可逐步弃用） |
| 备注 | 可选 | |

- **关联**：订单、套餐；下挂「设备」。
- **查重规则**：同一订单内同套餐多行应合并为一行（建单时检查）。
- **新增 / 更新规则**：
  - **已有设备进场的明细行：不可更换套餐、不可删除**（减设备先撤机）。
  - 调低数量只做风险提示；新增明细行随时可以。

## 表 7｜设备

**业务用途**：打印机台账，业务最核心的一张表；一台设备把客户侧与供应商侧连接在一起。

| 字段 | 必要性 | 说明 |
|---|---|---|
| 设备编码 | 必填 | 解析优先级：手填 > 供应商资产编码 > 自动生成（P0001 起）。与「运行中」设备重名须拒绝；不做全局唯一（不同供应商可同号） |
| 供应商资产编码 | 可选 | 供应商自己的设备编号 |
| 所属订单明细 | 必填 | 关联订单明细表；客户、地址、套餐由此自动追溯 |
| 机型 | 必填 | 关联机型库 |
| 进场日期 | 必填 | 计费与抄表起点 |
| 退场日期 | 可选 | 撤机 / 换机时填写 |
| 黑白初始读数 | 必填 | 第一期抄表的上期读数 |
| 彩色初始读数 | 彩色机必填 | 黑白机恒为 0 |
| 状态 | 必填 | 运行中 / 已换机 / 已撤机 |
| 上一台设备 | 可选 | 换机链：指向被替换的旧设备 |
| 抄表二维码 | 可选 | 免登录抄表入口（如继续沿用 Web 抄表页则存链接） |
| 备注 | 可选 | |

- **关联**：订单明细、机型、上一台设备（自关联）；下挂「抄表记录」。
- **自动计算**（如需展示）：所属客户、安装地址、套餐名称——全部由订单明细带出，**不在设备表重复保存**。
- **不应重复保存**：客户名、地址、套餐价格、供应商名等可通过关联得到的一切字段。
- **查重规则**：进场前先按「设备编码 / 供应商资产编码」查运行中设备，重名须人工确认。
- **新增 / 更新规则**：
  - 进场只在「已部署 < 数量」的明细下进行，创建即「运行中」。
  - 换机：旧机 → 已换机 + 退场日期 = 换机日期；新机 → 运行中 + 进场日期 = 换机日期 + 上一台设备指向旧机 + 新初始读数；客户订单明细沿用原机。
  - 撤机：状态 → 已撤机 + 退场日期（不早于进场日期）。
  - 已换机 / 已撤机设备：不删除、不修改，历史永久保留。

## 表 8｜抄表记录

**业务用途**：每台设备每个自然月的正式读数与用量；结算的唯一数据来源。

| 字段 | 必要性 | 说明 |
|---|---|---|
| 设备 | 必填 | 关联设备表 |
| 年份 / 月份 | 必填 | 业务月份（自然月）；（设备 + 年 + 月）唯一 |
| 上期黑白读数 | 必填 | 默认 = 之前最近一条抄表的本期读数；无则为设备黑白初始读数 |
| 本期黑白读数 | 必填 | 表显累计读数 |
| 上期彩色读数 | 彩色机必填 | 同上规则；黑白机恒为 0 |
| 本期彩色读数 | 彩色机必填 | 黑白机禁止填写 |
| 黑白用量 | 自动计算 | 本期 − 上期 |
| 彩色用量 | 自动计算 | 本期 − 上期 |
| BW Equivalent 用量 | 自动计算 | 黑白用量 + 彩色用量 × 10 |
| 抄表照片 | 客户扫码必传 / 后台补录可选 | |
| 提交时间 | 自动 | |
| 状态 | 必填 | 已提交 / 已调整 |
| 调整说明 | 编辑时必填 | 修正必须留痕 |
| 操作人 | 可选 | |

- **关联**：设备。
- **自动计算**：三项用量；上期读数可自动带出。
- **不应重复保存**：任何结算金额（由用量 + 套餐 + 进退场日期现算）。
- **查重规则**：（设备 + 年 + 月）唯一；同月已有记录时只能编辑原记录，不能新增第二条。
- **新增 / 更新规则**：
  - 本期读数 ≥ 上期读数；目标月之后已有抄表时，本期读数 ≤ 下一期读数（黑白 / 彩色分别校验）。
  - 月份范围：进场月份 ≤ 抄表月份 ≤ 退场月份（未退场则至当前月）；不允许未来月份。
  - 修正走「编辑」：改读数 + 必填调整说明 + 状态变「已调整」，不删除重建。

## 结算的实现方式（智能表场景）

Web 平台中结算是实时计算函数。在智能表场景下，结算由 WorkBuddy 按《PRINTING_OPERATIONS_RULES.md》第 5 章现算现报，**不在台账中保存结算结果**：

1. 取设备最近一个抄表月份（季度单则取最近季度内各月）；
2. 按月算在场天数（进场计入、退场不计）→ 折算月租与免费额度 → 超印 → 当月金额；
3. 客户侧用订单明细的客户套餐；供应商侧用供应商套餐（缺失则应付与毛利报「未配置」，不阻塞客户侧）；
4. 免费额度逐设备逐月独立，不共享；
5. 季度 = 季度内各月结果相加；订单 = 同期各台设备相加。

## 推荐视图

| 视图 | 所在表 | 筛选条件 |
|---|---|---|
| 待收押金 | 订单 | 押金收款日期为空 且 状态 ≠ 已取消 |
| 待进场 | 订单明细 | 已部署台数 < 数量 且 所属订单状态 ∈（草稿, 履约中） |
| 在用设备 | 设备 | 状态 = 运行中 |
| 本月待抄 | 设备 | 状态 = 运行中 且 本期业务月份无抄表记录（本期 = 上一自然月） |
| 本期已抄 | 抄表记录 | 年份 / 月份 = 本期业务月份 |
| 已结束订单 | 订单 | 状态 = 已结束 |
| 已换机 / 已撤机设备（历史） | 设备 | 状态 ∈（已换机, 已撤机） |
| 即将到期订单 | 订单 | 结束日期 ≤ 今天 + 90 天 且 状态 = 履约中 |
